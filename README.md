## 🌟 Overview

Welcome to the personal portfolio repository of **Sivasubramanian M** — an AI & Data Science specialist, Project Coordinator Trainee, and passionate product builder based in Chennai, India. 

Engineered with **React 18**, **Vite**, and **Tailwind CSS**, this portfolio combines visual aesthetics with subtle physics-based motion tracking, responsive layouts, and interactive components.

---

## ✨ Key Features

- 🎯 **Interactive Cyber Motion Tracker**: Real-time cursor tracking canvas that dynamically illuminates grid coordinates and draws subtle proximity radar connections.
- 🧲 **Magnetic Dual-Ring Cursor**: Custom fluid spring-interpolated cursor follower that expands on interactive cards, buttons, and links.
- 📐 **3D Perspective Tilt Facecard**: Interactive portrait frame that tracks cursor coordinates with dynamic three-dimensional perspective tilt.
- 🎨 **Dynamic Accent Color Switcher**: Real-time theme switcher (Indigo, Emerald, Cyan, Rose, Amber) with ambient aurora glow harmonization.
- 💼 **Categorized Career Timelines**: Interactive 3-section tabbed experience separating **Full Time**, **Internships**, and **Part-Time** roles with live count badges.
- 🚀 **1-Click Project Hub**: Card-focused showcase linking directly to live production builds (Vercel), Figma prototypes, and GitHub repositories without modal friction.
- 🤖 **Interactive Virtual Assistant**: Built-in conversational portfolio bot answering questions regarding technical skills, experience, and education.
- ⚡ **Optimized Performance**: Zero heavy dependencies, lightning-fast Vite bundling, and responsive mobile-first design.

## 💻 Getting Started Locally

To run this portfolio on your local environment:

### Prerequisites
- Node.js (version 18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sivsubramanian/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
